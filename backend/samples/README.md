# Sample Test Documents

This directory contains test cases representing various real-world examination documents:
1. `sample_01_clean.pdf` - High quality digitally generated multi-question examination paper.
2. `sample_02_scanned.pdf` - Scanned exam paper requiring OCR / image processing.
3. `sample_03_low_quality.png` - Low-resolution / noisy scan with imperfect text.
4. `sample_04_multi_page_question.pdf` - Examination where Question 2 spans across Page 1 and Page 2.
5. `sample_05_question_paper.pdf` - Question paper with no embedded answers.
6. `sample_06_separate_answer_key.pdf` - Standalone answer key to be linked with `sample_05`.
7. `sample_07_invalid.txt` - Invalid/unsupported format to verify input rejection and error handling.
